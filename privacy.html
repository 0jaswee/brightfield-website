This website

This static website does not contain a student database, login system, analytics tracker, or an application submission form. Your browser loads the website files from the host.

External application form

If an application link is configured, it opens Google Forms. Data you submit there is handled through that form and the institution’s account, not stored in this website’s GitHub repository.

For the institution

Before collecting real information, replace this sample notice with your actual privacy information: who operates the form, why each field is needed, who can access responses, how long records are kept, and whom applicants can contact. Set appropriate permissions on both the form and any response Sheet.

During learning

Use made-up details. Do not publish students’ personal information, private documents, or response spreadsheets in a public repository.
